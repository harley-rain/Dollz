# Dollz!
Dollz! is a nostolgic themed dress up desktop application created using only python and pygame. 



> [!NOTE]
> On my mac I was getting an error importing the library to vs code. After you make sure pygame is installed locally, in vs code: cmd + shift + p -> Python: Select Interpreter -> select the global version that contains your pygame install,usually usr/bin/python3. this fixed my error
