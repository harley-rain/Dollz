# Dollz!
Dollz! is a nostolgic themed dress up game desktop application created using only python and pygame.
Created by Harley Coxon

to install pygame:
• Windows: Press Win + R, type cmd, and press Enter.
• Mac / Linux: Open your Terminal application

Run pygame Installation command: pip install pygame 
• Mac/Linux: pip3 install pygame
• Windows (Python Launcher): py -m pip install pygame
• Explicit Python 3 call: python3 -m pip install pygame 
or install using a env if your getting pip not found error : pip install pygame-ce
.vscode folder contains enviornment settings 

check: pygame --version
